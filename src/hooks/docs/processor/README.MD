# 检测服务

## 概览
检测服务 hook 是项目运行时的第一道统一检查链，负责缓存回填、黑白名单、群授权、全员禁言等前置拦截。它对外是一个整体的被动 hook，而不是需要继续下钻的多子功能插件。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 用法
- 别名: 缓存回填, 拦截链, sync, check
- 指令: 被动触发
- Demo: hook-processor-main.png
## 说明
hook 会先执行运行时同步，再执行运行时检查。同步阶段负责回填用户、群、群成员缓存；检查阶段按固定顺序处理忽略用户、超管放行、全局黑名单、群授权、全员禁言和群黑名单。只有显式声明 `no_check=True` 的系统插件可以跳过这条检查链。
## 前置条件
收到一个带用户或群上下文的事件，且目标插件已经加载到当前运行时。
## 完整流程
同步动作对用户透明；若检查链命中阻断条件，事件会在进入业务 matcher 前被忽略。
```demo
SYSTEM: 收到一条群消息事件。
SYSTEM: 先执行用户/群/成员缓存同步，回填昵称、群名和群角色等运行时缓存。
SYSTEM: 再按固定顺序执行忽略用户、超管、黑名单、群授权和全员禁言检查。
SYSTEM: 如果当前群未授权，事件会在进入业务插件前被提前忽略。
```
## 失败情况
如果缓存依赖的 API 不可用，可能导致部分字段缺失；如果群缓存缺失且无法补齐，默认会阻止群事件继续进入业务插件。
