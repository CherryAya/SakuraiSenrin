# 检测服务

## 概览
全局拦截器，用于预处理事件

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 用法
- Help: `processor`
- 别名: 缓存回填, 拦截链, sync, check
- 指令: 被动触发
- Demo: hook-processor-main.png
## 说明
运行时同步、检查工作，在配置 `no_check=True` 的插件中，会跳过所有检查链。

## 前置条件
需要事件先进入 NoneBot 运行时预处理链路。

## 完整流程
被动完成，用户无感
```demo
SYSTEM: 收到一条群消息事件。
SYSTEM: 先执行用户/群/成员缓存同步，回填昵称、群名和群角色等运行时缓存。
SYSTEM: 再按固定顺序执行忽略用户、超管、黑名单、群授权和全员禁言检查。
SYSTEM: 如果当前群未授权，事件会在进入业务插件前被提前忽略。
```

## 失败情况
缓存同步或鉴权检查异常时会记录日志并按运行时保护策略中断后续业务处理。
