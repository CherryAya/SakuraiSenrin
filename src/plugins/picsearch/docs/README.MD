# 图片搜索

## 概览
图来！🫳

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- Help: `picsearch`
- 别名: 搜图
- 指令: `搜图 [saucenao|ascii2d]`
- Demo: picsearch-search.png

## 说明
回复一条带图片的消息，并发送 `搜图` 即可。

引擎默认用 `saucenao`，另外还支持 `ascii2d`。

## 前置条件
- 同一用户默认有 30 秒冷却。

## 完整流程
如果有多张图，还请选择序号，一次最多搜 3 张。
```demo
USER: [回复一条图片消息] 搜图
BOT: 正在搜索第 1 张图片，请稍后...
BOT: 第 1 张图片搜索结果：
引擎：saucenao
相似度：89.12
标题：示例标题
作者：示例作者
链接：https://example.com/source
```

## 失败情况
未回复图片消息、冷却中、第三方搜图接口失败或返回空结果时，会返回明确提示。
