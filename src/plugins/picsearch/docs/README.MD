# 图片搜索

## 概览
这个插件用于对回复消息中的图片执行搜图，支持 `SauceNAO` 和 `ASCII2D` 两种引擎。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- 别名: 搜图
- 指令: `搜图 [saucenao|ascii2d]`
- Demo: picsearch-search.png
## 说明
需要先回复一条包含图片的消息，再发送 `搜图`。如果不指定引擎，默认使用 `saucenao`。也可以发送 `搜图 ascii2d` 显式切换引擎。
## 前置条件
- 必须回复一条包含至少一张图片的消息。
- 若使用 `saucenao`，需要已配置 `SAUCENAO_KEY`。
- 同一用户默认有 30 秒冷却。
## 完整流程
单图会直接开始搜索；多图会要求输入图片序号，最多允许一次搜索 3 张。
```demo
USER: [回复一条图片消息] 搜图
BOT: 正在搜索第 1 张图片，请稍后...
BOT: 第 1 张图片搜索结果：
引擎：saucenao
相似度：89.12
标题：示例标题
作者：示例作者
链接：https://example.com/source
```
## 失败情况
- 没有回复图片时，会提示先回复图片消息。
- 引擎名无效时，会提示可用引擎。
- 多图选择越界、不是数字、或超过 3 张时，会要求重新输入。
- 搜索接口失败、无结果或缩略图下载失败时，会返回明确降级提示。
