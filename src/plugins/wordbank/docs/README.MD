# 词库模块

## 概览
词库模块当前仍是总入口占位，用于保留未来词库相关能力的帮助入口。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `placeholder` 词库占位说明: 告知当前词库能力仍在开发中。

## 子功能详情
### `placeholder` 词库占位说明
- 摘要: 告知当前词库能力仍在开发中。
- 别名: 占位, 开发中
- 指令: 文档查询
- Demo: wordbank-placeholder.png
#### 说明
