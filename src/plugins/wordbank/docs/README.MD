# 词库模块

## 概览
词库模块提供低资源优先的群聊词库能力。`wordbank` 负责完整词库管理、运行时匹配、图片指纹和日志；`study` 只是快捷添加入口。运行时使用内存索引匹配文本、图片和事件触发词，普通文本消息路径不查询数据库；新增、删除、恢复后通过延迟重建刷新索引。检测到 `revoke` / `recall` 相关信号时会直接跳过匹配，不回复也不写日志；`wordbank / 词库 / wordbank.help` 可查看帮助，`wordbank add` / `wordbank.add` / `添加词条` 的引导流程里如果收到撤回信号，会发送取消提示并中止，连续输错 3 次也会终止。图片回复和图片触发都统一走 `wordbank add`，不再提供单独的图片子命令。为兼容旧入口，`wordbank.add`、`wordbank.search`、`wordbank.delete`、`wordbank.restore`、`wordbank.support`、`wordbank.vote` 和常用中文直达命令会自动转入对应新版子命令。

## 权限与触发
- 触发方式: 指令触发 / 被动触发
- 权限: 普通用户

## 子功能目录
- `add` 添加词条: 添加文本回复、图片回复或图片触发词条。
- `search` 搜索词条: 按触发词或响应词查询现有词条。
- `delete` 删除词条: 软删除指定词条并刷新索引。
- `support` 支持删除投票: 普通用户参与当前群词条删除投票。
- `vote` 查看删除投票: 查看当前群删除投票状态。
- `restore` 恢复词条: 恢复已删除词条并刷新索引。
- `reply-shortcut` 回复管理: 回复机器人自动回复后查看详情、状态摘要、删除或恢复词条。
- `passive` 被动匹配: 文本、图片、@、戳一戳或入退群事件命中词条后自动回复文本或图片，撤回信号直接跳过。

## 子功能详情
### `add` 添加词条
- 摘要: 添加文本或图片相关词条。
- 别名: 添加, 学习, wordbank.add, 添加词条
- 指令: `wordbank add 触发词 => 响应词`
- 兼容指令: `wordbank.add 触发词 => 响应词`、`添加词条 触发词 => 响应词`
#### 说明
默认触发模式为 `contains`，短词默认转为 `fullmatch` 并使用较低概率。高级选项支持 `--mode`、`--scope`、`--prob`、`--weight`、`--role`、`--call`。`wordbank add 触发词 [图片]` 表示文本触发、图片回复；`wordbank add [图片] => 响应词` 表示图片触发、文本回复；`wordbank add 触发词 => 响应词 [图片]` 表示文本触发、图文混排回复。图片入库时会计算 MD5、dHash、pHash、尺寸和文件大小，相似图片会归并到同一个 canonical image。`study 触发词 => 响应词` 会走同一套文本添加逻辑；旧版 `study <a|m> <t|f> 触发词 响应词` 也会转换为新版固定 scope。引导任一步收到 `revoke` / `recall` 会发送取消提示并中止；连续输错 3 次会强制终止对话。
#### 前置条件
当前用户所在群聊需要通过运行时检查。
#### 完整流程
```demo
USER: #wordbank.add
BOT: 请输入触发词：
USER: 晚安
BOT: 请输入响应词：
USER: 做个好梦
BOT: 请选择生效范围：
1. 当前群（默认）
2. 所有群
3. 仅自己
4. 仅私聊
USER: 1
BOT: 是否需要高级选项？发送 n 跳过；需要请直接输入参数，例如 --mode fullmatch --prob 0.5 --weight 3 --role admin --call 60:0:3
USER: n
BOT: 词条已加入词库
ID: 12
触发: 晚安
响应: 做个好梦
模式: contains
范围: current_group
概率: 1
权重: 3
USER: 大家晚安啦
BOT: 做个好梦
USER: #wordbank add 是这张图喔 [图片]
BOT: 词条已加入词库
ID: 13
触发: 是这张图喔
响应: [图片:7]
模式: contains
范围: current_group
概率: 1
权重: 3
USER: #wordbank add [图片] => 是这张图喔
BOT: 词条已加入词库
ID: 14
触发: [图片:7]
响应: 是这张图喔
模式: fullmatch
范围: current_group
概率: 1
权重: 3
```
#### 失败情况
触发词或响应词为空、图片下载失败、图片无法识别、规则字段冲突、概率和权重越界时会返回当前群语言的原因；引导中若检测到 `revoke` / `recall` 会发送取消提示并中止，连续输错 3 次会强制终止对话。

### `search` 搜索词条
- 摘要: 查询词库中的触发词和响应词。
- 别名: 查询, 搜索, wordbank.search, 搜索词条
- 指令: `wordbank search [关键词] [--page 页码] [--limit 每页数量]`
- 兼容指令: `wordbank.search [关键词]`、`搜索词条 [关键词]`
#### 说明
搜索按需查询数据库，默认每页 10 条，最多每页 20 条。分页只读取当前页和一条额外记录判断是否还有下一页，不参与被动消息热路径。
#### 前置条件
无。
#### 完整流程
```demo
USER: #wordbank search 晚安 --page 1 --limit 10
BOT: 词库搜索结果 (第 1 页):
#12 [contains/current_group] 晚安 => 做个好梦
还有更多结果，可使用 --page 2 --limit 10 查看下一页。
```
#### 失败情况
没有命中时返回空结果说明；页码或每页数量非法时返回当前群语言的原因。

### `delete` 删除词条
- 摘要: 软删除指定词条。
- 别名: 删除, remove, wordbank.delete, wordbank.del, 删除词条
- 指令: `wordbank delete <id>`
- 兼容指令: `wordbank.delete <id>`、`wordbank.del <id>`、`删除词条 <id>`
#### 说明
删除后词条不会参与匹配，数据仍保留以便恢复。兼容入口仍使用新版按 ID 删除模型，不恢复旧版回复消息审批流。创建者、当前群管理员或超级用户可直接删除；普通用户删除当前群可见但不属于自己的词条时，会自动发起删除投票并计入一票。投票达标后词条会被软删除并通过延迟重建移出运行时索引。
#### 前置条件
需要提供数字词条 ID。投票删除只在群聊内生效，并且只允许对当前群词条、当前群内个人词条或全群词条发起。
#### 完整流程
```demo
USER: #wordbank delete 12
BOT: 词条 #12 已删除。
USER: 大家晚安啦
SYSTEM: 词条已软删除，普通消息不会触发回复。
USER: #wordbank delete 18
BOT: 你没有直接删除词条 #18 的权限，已发起删除投票 #3 并计入你的支持票。
当前支持票: 1/3
其他群友可发送 wordbank support 3 或 支持删除 3 参与。
```
#### 失败情况
ID 非数字、词条不存在或当前用户没有操作权限时返回明确说明。

### `support` 支持删除投票
- 摘要: 为当前群的删除投票增加支持票。
- 别名: 支持, 支持删除, wordbank.support
- 指令: `wordbank support <vote_id>`
- 兼容指令: `wordbank.support <vote_id>`、`支持删除 <vote_id>`
#### 说明
同一用户对同一投票只计一票。投票达到默认 3 票后，目标词条会立即软删除并刷新运行时索引。已结束投票不会重复删除词条。
#### 前置条件
需要在投票发起的群聊中使用，并提供数字投票 ID。
#### 完整流程
```demo
USER: #wordbank support 3
BOT: 已支持删除投票 #3。
词条: #18
当前支持票: 2/3
USER: #支持删除 3
BOT: 删除投票 #3 已达标，词条 #18 已删除。
支持票: 3/3
```
#### 失败情况
投票 ID 非数字、投票不存在、投票不属于当前群或投票已结束时返回明确说明。

### `vote` 查看删除投票
- 摘要: 查看当前群删除投票状态。
- 别名: 投票, 查看投票状态, 查看投票结果, wordbank.vote
- 指令: `wordbank vote <vote_id>`
- 兼容指令: `wordbank.vote <vote_id>`、`查看投票状态 <vote_id>`
#### 说明
用于查询旧版投票删除流程的进度，显示投票 ID、目标词条、状态和支持票数。
#### 前置条件
需要在投票发起的群聊中使用，并提供数字投票 ID。
#### 完整流程
```demo
USER: #wordbank vote 3
BOT: 删除投票 #3
词条: #18
状态: open
支持票: 2/3
```
#### 失败情况
投票 ID 非数字、投票不存在或投票不属于当前群时返回明确说明。

### `restore` 恢复词条
- 摘要: 恢复已删除词条。
- 别名: 恢复, wordbank.restore, 恢复词条
- 指令: `wordbank restore <id>`
- 兼容指令: `wordbank.restore <id>`、`恢复词条 <id>`
#### 说明
恢复后通过延迟重建重新加入运行时索引。
#### 前置条件
目标词条已被删除。创建者可以恢复自己的词条；当前群管理员或群主可以恢复本群词条；超级用户可以恢复任意词条。
#### 完整流程
```demo
USER: #wordbank restore 12
BOT: 词条 #12 已恢复。
USER: 大家晚安啦
BOT: 做个好梦
```
#### 失败情况
ID 非数字、词条不存在或当前用户没有操作权限时返回明确说明。

### `passive` 被动匹配
- 摘要: 普通消息命中词条后自动回复。
- 别名: 被动, 自动回复
- 指令: 无
#### 说明
文本先走内存索引匹配，图片只在消息包含图片时下载并比对本地热缓存。响应可以是纯文本，也可以是 `wordbank add` 保存的图片或图文混排。@、戳一戳、入群和退群会被转换成固定事件触发词后复用同一套内存索引与规则判断。检测到事件名、`notice_type`、`sub_type`、消息段类型或原始消息里包含 `revoke` / `recall` 时直接跳过。

可添加的常用事件触发词:
- `event:at`: 有人 @ 机器人。
- `event:poke`: 有人戳一戳机器人。
- `event:join` / `event:group_increase`: 群成员加入。
- `event:leave` / `event:group_decrease`: 群成员退出或被移出。
#### 前置条件
词条已启用，且运行时检查允许当前消息继续处理。
#### 完整流程
```demo
USER: 大家晚安啦
BOT: 做个好梦
USER: #wordbank add event:poke => 别戳啦
BOT: 词条已加入词库
USER: [戳一戳机器人]
BOT: 别戳啦
SYSTEM: 检测到 group_recall / message_revoke / recall 片段时直接跳过，不回复也不写匹配日志。
```
#### 失败情况
没有命中、规则不通过、概率未命中、图片下载失败或检测到撤回信号时不回复。

### `reply-shortcut` 回复管理
- 摘要: 回复机器人词库自动回复后，用旧式短命令管理对应词条。
- 别名: info, 详情, history, 审批历史, del, delete, 删除, rst, restore, 恢复
- 指令: 回复机器人词库自动回复并发送 `info` / `history` / `del` / `rst`
- 兼容指令: `详情`、`审批历史`、`删除`、`恢复`、`del response`、`delete trigger`、`restore response`
#### 说明
词库自动回复发送成功后会记录该回复消息 ID 与命中的词条、触发词、响应词的关系。之后回复这条机器人消息并 @ 机器人发送短命令即可管理词条。`info` / `详情` 会查看词条详情；`history` / `审批历史` 在新版模型中返回状态摘要，因为普通添加已立即以 `approved` 状态入库，不再保留旧版审批流水；`del` / `delete` / `删除` 复用新版按词条删除权限和投票删除规则；`rst` / `restore` / `恢复` 复用新版恢复权限。
#### 前置条件
必须回复一条由词库被动匹配发出的机器人消息；普通用户只能直接操作自己创建的词条，群管理员可操作当前群词条，超级用户可操作任意词条。
#### 完整流程
```demo
USER: 大家晚安啦
BOT: 做个好梦
USER: [回复上条机器人消息] @机器人 详情
BOT: 词条详情 #12
状态: approved
触发: [contains] 晚安
响应: 做个好梦
USER: [回复上条机器人消息] @机器人 删除
BOT: 词条 #12 已删除。
```
#### 失败情况
未回复词库自动回复、消息记录不存在、词条已被清理、当前用户没有删除或恢复权限时会返回明确说明。被回复消息本身如为撤回类 `revoke` / `recall` 信号，不会被被动词库记录。
