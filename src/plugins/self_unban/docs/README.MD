# 自助解封

## 概览
给被拉黑的用户和被封禁的群聊一个受控的自助恢复入口。每个用户、每个群聊生命周期内最多只能成功自助解封 2 次，第 3 次及以上必须联系超管。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户 / 群管理员

## 子功能目录
- `user` 用户自助解封: 解除自己的全局或群级黑名单，需要填写不少于 10 个字的理由。
- `group` 群聊自助解封: 解除当前群封禁，仅群主或管理员可发起，解封后群状态回到未授权。

## 子功能详情
### `user` 用户自助解封
- 摘要: 解除自己的全局或群级黑名单，需要填写不少于 10 个字的理由。
- 指令: `#self.unban user [--group <group_id>]`
- 别名: 自助解封用户, self.unban user
#### 说明
私聊中不带 `--group` 时，默认申请解除全局黑名单；群聊中不带 `--group` 时，默认申请解除当前群的群级黑名单。

理由必须为非空且至少 10 个字。成功后会消耗 1 次额度，并同步通知超管。
#### 前置条件
当前对象确实处于对应作用域的黑名单中，且该用户历史成功自助解封次数少于 2 次。
#### 完整流程
```demo
USER: #self.unban user
BOT: 请输入本次全局自助解封理由（至少 10 个字）。本次通过后会消耗 1 次额度，当前剩余 2 次。
USER: 之前连续刷屏已经停止，后续会遵守群规正常交流
BOT: 已解除全局黑名单。已使用 1/2 次自助解封，剩余 1 次。
```
#### 失败情况
理由为空、全空白或少于 10 个字时会要求重填；如果当前不在对应黑名单中，或已达到 2 次上限，会直接拒绝并提示联系超管。

### `group` 群聊自助解封
- 摘要: 解除当前群封禁，仅群主或管理员可发起，解封后群状态回到未授权。
- 指令: `#self.unban group`
- 别名: 自助解封群聊, self.unban group
#### 说明
该命令只能在目标群内发起。成功后只会解除封禁，不会自动恢复授权。
#### 前置条件
当前群状态为 `BANNED`，发起者为群主或管理员，且该群历史成功自助解封次数少于 2 次。
#### 完整流程
```demo
USER: #self.unban group
BOT: 请输入本群自助解封理由（至少 10 个字）。本次通过后会消耗 1 次额度，当前剩余 1 次。
USER: 原先的风控问题已经处理完毕，后续不会再出现禁言机器人行为
BOT: 已解除本群封禁，当前状态变更为未授权。已使用 2/2 次自助解封，剩余 0 次。
```
#### 失败情况
普通群成员不能代群申请；未封禁群、次数已用尽的群、以及缺少合规理由的申请都会被拒绝。
