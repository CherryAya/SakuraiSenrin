# 群组邀请处理

## 概览
群组邀请处理模块负责记录每一次群邀请，并根据群当前状态做自动同意、自动拒绝或上报超级管理员处理。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 子功能目录
- `auto-approve-authorized` 已授权群自动放行: 已授权群的邀请直接放过，不再重复打断。
- `auto-reject-banned` 封禁群自动拒绝: 黑名单群的邀请自动拒绝并通知相关人。
- `report-pending` 普通邀请上报: 普通邀请写入记录并通知超管审批。

## 子功能详情
### `auto-approve-authorized` 已授权群自动放行
- 摘要: 已授权群的邀请直接放过，不再重复打断。
- 别名: 自动放行
- 指令: 被动触发
- Demo: notice-invite-auto-approve-authorized.png
#### 说明
如果被邀请的群已经在数据库里处于工作状态，模块不会重复让超管审批。
#### 前置条件
群记录存在，且状态为 `AUTHORIZED` 或 `DORMANT`。
#### 完整流程
事件进入后直接结束处理。
```demo
SYSTEM: 已授权群 114514 再次发来邀请。
自动跳过人工审批，不再额外推送消息。
```
#### 失败情况
如果群状态判断错误，可能会产生重复邀请记录，需要通过仓库日志排查。

### `auto-reject-banned` 封禁群自动拒绝
- 摘要: 黑名单群的邀请自动拒绝并通知相关人。
- 别名: 自动拒绝, 黑名单邀请
- 指令: 被动触发
- Demo: notice-invite-auto-reject-banned.png
#### 说明
如果群已被标记为封禁状态，模块会自动拒绝邀请，并通知邀请者与超级管理员。
#### 前置条件
群记录存在，且状态为 `BANNED`。
#### 完整流程
对邀请者和超管分别发送通知。
```demo
SYSTEM: 封禁群 114514 发来邀请。
BOT: [私聊邀请者] 群聊已被拉黑，凛凛不想加入此群组。
BOT: [私聊超管] 黑名单群组发起邀请，已自动拒绝。
```
#### 失败情况
如果私聊发送失败，不会阻止拒绝动作本身。

### `report-pending` 普通邀请上报
- 摘要: 普通邀请写入记录并通知超管审批。
- 别名: 邀请上报
- 指令: 被动触发
- Demo: notice-invite-report-pending.png
#### 说明
对于既未授权也未封禁的普通群，模块会记录邀请，并把通知发给超管等待处理。
#### 前置条件
需要能够解析出群号、邀请者以及可选 flag。
#### 完整流程
先写邀请记录，再给邀请者和超管发通知。
```demo
SYSTEM: 新群 114514 发来邀请。
BOT: [私聊邀请者] 谢谢您对凛凛发起的邀请 ^_^
BOT: [私聊超管] 📩 新的邀请事件通知
```
#### 失败情况
如果邀请消息发送失败，对应 message_id 记录也不会建立，之后无法使用回复快捷审批。
