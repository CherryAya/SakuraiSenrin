# 用户事件处理

## 概览
用户事件处理模块目前只负责好友请求这一件事：自动同意申请、补充用户记录，并通知超级管理员。它是一个单功能被动插件，不需要再拆子功能目录。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 用法
- Help: `notice.user`
- 别名: 好友申请
- 指令: 被动触发
- Demo: notice-user-main.webp
## 说明
> [!TIP]
> 模块收到好友请求后，不会立刻秒同意。
>
> 它会先随机延迟一小段时间，尽量避免行为模式过于机械。

> [!TIP]
> 请求同意后，还会顺手补充用户库记录，并通知超级管理员。
## 前置条件
收到 `FriendRequestEvent`，且 Bot 可以正常调用添加好友接口。
## 完整流程
同意好友请求后再向超管汇报。
```demo
SYSTEM: 收到来自 12345 的好友请求。
BOT: 自动同意好友请求。
BOT: [私聊超管] 收到了新的好友请求，已同意：12345
```
## 失败情况
如果好友信息获取失败或发送超管通知失败，需要通过日志定位，当前不会重试。
