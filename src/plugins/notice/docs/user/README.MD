# 用户事件处理

## 概览
用户事件处理模块目前主要负责好友请求：自动同意申请、补充用户记录，并通知超级管理员。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 子功能目录
- `friend-request` 好友请求处理: 自动同意好友请求并通知超管。

## 子功能详情
### `friend-request` 好友请求处理
- 摘要: 自动同意好友请求并通知超管。
- 别名: 好友申请
- 指令: 被动触发
- Demo: notice-user-friend-request.png
#### 说明
模块收到好友请求后会延迟一段随机时间再同意，以减轻行为模式过于机械的问题。随后会补充用户库记录并通知超管。
#### 前置条件
收到 `FriendRequestEvent`，且 Bot 可以正常调用添加好友接口。
#### 完整流程
同意好友请求后再向超管汇报。
```demo
SYSTEM: 收到来自 12345 的好友请求。
BOT: 自动同意好友请求。
BOT: [私聊超管] 收到了新的好友请求，已同意：12345
```
#### 失败情况
如果好友信息获取失败或发送超管通知失败，需要通过日志定位，当前不会重试。
