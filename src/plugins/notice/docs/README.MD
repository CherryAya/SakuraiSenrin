# 通知模块总览

## 概览
通知模块处理项目里的系统被动事件，主要负责群事件、邀请事件和好友请求。默认不出现在普通帮助索引中，但支持精确查询。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 子功能目录
- `group` 群组事件处理: 处理被踢、被禁言、入群同步和群名变更。
- `invite` 群邀请处理: 记录并上报群邀请，同时对已授权或封禁群做自动处理。
- `user` 好友请求处理: 自动同意好友请求并通知超管。

## 子功能详情
### `group` 群组事件处理
- 摘要: 处理被踢、被禁言、入群同步和群名变更。
- 别名: notice.group
- 指令: `#help 群组事件处理`
- Demo: notice-overview-group.png
#### 说明
这是群组事件处理的聚合入口。
#### 前置条件
机器人需已收到相关 OneBot 通知事件。
#### 完整流程
先进入群组事件处理模块，再按事件查看 demo。
```demo
USER: #help 通知模块总览 group
BOT: 群组事件处理负责禁言退群、被踢清理和入群同步。
SYSTEM: 继续发送 #help 群组事件处理 ban-cleanup 查看完整流程。
```
#### 失败情况
如果希望在索引中直接展示该模块，需要同步调整 metadata 的 visible 设置。

#### 说明

#### 完整流程
先进入群邀请处理模块，再按事件查看 demo。
