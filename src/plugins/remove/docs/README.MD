# 退群

## 概览
收到，凛凛这就跑路👋

## 权限与触发
- 触发方式: 指令触发
- 权限: 群管理员

## 用法
- Help: `remove`
- 别名: remove, 退群
- 指令: `#remove`
- Demo: remove-guide.webp
## 说明
你跑不过凛凛你信吗（笑）

## 前置条件
仅群主、管理员、邀请者有权限使用。

## 完整流程
```demo
USER: #remove
BOT: 是否确认退群？输入 y 或 yes 确认，其他内容取消：
USER: y
BOT: 请输入退群原因：
USER: 例行维护，暂时停用
BOT: 走了走了，再见啦！
原因：例行维护，暂时停用
```
