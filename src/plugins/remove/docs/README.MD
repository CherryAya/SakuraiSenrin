# 退群说明

## 概览
这个插件当前承担“退群规范说明”的职责，用于告诉群管理者怎样让机器人安全退出群聊，而不是直接把机器人踢出。

## 权限与触发
- 触发方式: 指令触发
- 权限: 群管理员

## 子功能目录
- `guide` 退群指引: 解释正确的退群流程与注意事项。

## 子功能详情
### `guide` 退群指引
- 摘要: 解释正确的退群流程与注意事项。
- 别名: remove, 退群
- 指令: `#remove`
- Demo: remove-guide.png
#### 说明
当前项目里没有独立的退群执行命令逻辑，这份文档的作用是给群管理者一个统一说明，避免因为直接移除机器人而触发误判。
#### 前置条件
需要由当前群的管理者阅读并按说明执行后续操作。
#### 完整流程
先阅读说明，再联系维护方或按约定完成退群申请。
```demo
USER: #remove
BOT: 如需让机器人退出群聊，请不要直接移除。
请先联系维护方或反馈群说明退群原因，再由管理员处理。
```
#### 失败情况
如果未来接入真实命令实现，README 中的说明和 demo 需要同步更新。
