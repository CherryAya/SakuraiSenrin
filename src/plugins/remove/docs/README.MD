# 退群

## 概览
这个插件用于让机器人从当前群聊安全退出，同时同步更新群状态并向超管发送退群报告。

## 权限与触发
- 触发方式: 指令触发
- 权限: 群管理员

## 子功能目录
- `leave` 发起退群: 由群管理员、群主或邀请者发起退群。

## 子功能详情
### `leave` 发起退群
- 摘要: 由群管理员、群主或邀请者发起退群。
- 别名: remove, 退群
- 指令: `#remove`
- Demo: remove-guide.png
#### 说明
发送指令后会进入两步确认：先确认是否退群，再填写退群原因。确认成功后，机器人会退出当前群，并向超管发送报告。
#### 前置条件
需要在群聊中触发，并且发起者必须满足以下之一：
- 当前群群主
- 当前群管理员
- 当前群邀请者
#### 完整流程
先发送 `#remove`，确认后再填写退群原因。
```demo
USER: #remove
BOT: 是否确认退群？输入 y 或 yes 确认，其他内容取消：
USER: y
BOT: 请输入退群原因：
USER: 例行维护，暂时停用
BOT: 走了走了，再见啦！原因：例行维护，暂时停用
BOT: 已从当前群聊退出: 测试群
```
#### 失败情况
- 私聊触发会被拒绝，并提示回到群聊中操作。
- 权限不足会明确提示仅群主、管理员或邀请者可发起。
- 若确认阶段输入的不是 `y/yes`，流程会直接取消。
- 若调用退群 API 失败，会返回明确失败提示，不会静默成功。
