# 用户反馈群密码

## 概览
这是一个虚拟社区说明节点，用于告诉群友如何获取用户反馈群的入群密码。

## 权限与触发
- 触发方式: 命令触发
- 权限: 普通用户

## 用法
- Help: `密码`
- 指令: `#密码`

## 说明
用户发送 `#密码` 后，凛凛会告知加入用户反馈群所需的密码。

当前插件仅作为社区文档节点存在，用于在帮助系统中说明该功能入口。

## 前置条件
无。

## 完整流程
```demo
USER: #密码
BOT: 请查看用户反馈群入群密码，并按提示加入反馈群。
```

## 失败情况
当前为纯说明节点，没有额外失败分支；若帮助系统不可用，则不会返回该说明。
