# 帮助文档

## 概览
统一汇总项目内插件文档，并支持按插件名、别名或子功能名继续查询。首页只展示当前用户有权限查看的插件。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `index` 插件索引: 查看当前有权限使用的插件列表。
- `plugin-detail` 插件详情: 查看某个插件的功能与指令。
- `feature-detail` 子功能详情: 查看某个子功能的指令、注意事项与 demo 图。

## 子功能详情
### `index` 插件索引
- 摘要: 查看当前有权限使用的插件列表。
- 别名: 总表, 列表
- 指令: `#help`
- Demo: help-index.png
#### 说明
不带参数发送 `#help` 时，帮助文档会返回当前用户有权限查看的插件列表。这个列表只展示 `visible=True` 的插件。
#### 前置条件
机器人已正常启动，并至少加载了一个带 `extra.docs` 的项目插件。
#### 完整流程
先查看索引，再决定深入哪个插件。
```demo
USER: #help
BOT: 📖 ===== 帮助文档 =====
命令前缀: #help / #帮助
🔧 当前可用插件如下:
1. 帮助文档
  #help 帮助文档
2. 吹水记录
  #help 吹水记录
```
#### 失败情况
如果当前没有可展示插件，帮助文档会返回“当前暂无可展示插件文档”。

### `plugin-detail` 插件详情
- 摘要: 查看某个插件的功能与指令。
- 别名: 插件文档, 详情
- 指令: `#help <插件名>`
- Demo: help-plugin-detail.png
#### 说明
当用户明确指定插件名后，帮助文档会返回该插件的功能名、指令和注意事项，并在下方附上 demo 图。
#### 前置条件
需要提供一个能够命中的插件名、模块名或插件别名。
#### 完整流程
先定位插件，再决定查看哪个子功能。
```demo
USER: #help 吹水记录
BOT: 📖 ===== 吹水记录 =====
1. 查看个人画像
  #水王
2. 查看周期榜单
  #水王 日榜|月榜|季榜|年榜|总榜
```
#### 失败情况
如果插件名不存在，会提示先发送 `#help` 查看总表；如果无权限查看，会返回权限提示；如果命中多个插件，会返回候选列表。

### `feature-detail` 子功能详情
- 摘要: 查看某个子功能的完整使用流程和 demo 图。
- 别名: 子功能, 功能详情
- 指令: `#help <插件名> <子功能名>`
- Demo: help-feature-detail.png
#### 说明
当用户继续补充子功能名后，帮助文档会返回该功能的功能名、指令、注意事项，并附上一张完整对话流程图。
#### 前置条件
插件名必须先能命中，子功能名需要命中 README 中定义的 slug、标题或别名。
#### 完整流程
推荐先看插件详情，再精确查询子功能。
```demo
USER: #help 吹水记录 ranking
BOT: 📖 ===== 吹水记录 / 查看周期榜单 =====
功能名: 查看周期榜单
指令:
  #水王 日榜|月榜|季榜|年榜|总榜
```
#### 失败情况
如果子功能名不存在，会提示“未找到子功能文档”；如果命中多个子功能，会返回歧义候选。
