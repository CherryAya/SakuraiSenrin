# 帮助文档

## 概览
你也好奇凛凛的技能树点在了什么奇怪的地方上吧（笑）

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- Help: `help`
- 别名: 总表, 列表
- 指令: `#help [插件名] [子功能名]`
- Demo: help-main.webp
## 说明
> [!TIP]
> 直接发送 `#help` 会先看到帮助总表，适合先确认有哪些插件和总览节点。
>
> 如果你已经知道目标功能，就继续在后面补插件名或子功能名，帮助中心会优先走精确命中，再回退到模糊匹配和歧义提示。

> [!TIP]
> 常见入口有两种：
>
> - `#help 图片搜索`：直接看某个插件说明
> - `#help 管理模块总览 group`：先进总览，再定位到子模块

## 完整流程
```demo
USER: #help
BOT: [展示帮助文档]
USER: #help 图片搜索
BOT: [直接展示搜图功能说明和 demo]
USER: #help 管理模块总览 group
BOT: [展示群组管理模块详情]
USER: #help 群组管理模块 ban
```
