# 帮助文档

## 概览
统一汇总项目内插件文档，并支持按插件名、别名或子功能名继续查询。简单功能会直接展示用法和 demo，复杂模块才保留分组入口。首页只展示当前用户有权限查看的插件。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- 别名: 总表, 列表
- 指令: `#help [插件名] [子功能名]`
- Demo: help-index.png

来看看凛凛是如何工作的吧！
## 前置条件
当你看到这条消息的时候，就代表凛凛已经成功运行起来啦！
## 完整流程
先看首页，再根据功能复杂度直接进入说明或继续下钻。
```demo
USER: #help
BOT: [展示帮助文档]
SYSTEM: 简单功能可直接发送 #help 图片搜索 / #help 退群 查看说明与 demo。
SYSTEM: 复杂模块可先发送 #help 词库模块 / #help 管理模块总览 查看分组入口。
USER: #help 图片搜索
BOT: [直接展示搜图功能说明和 demo]
USER: #help 管理模块总览 group
BOT: [展示群组管理模块详情]
USER: #help 群组管理模块 ban
SYSTEM: 再继续发送 #help 群组管理模块 ban 查看具体操作 demo。
```
## 失败情况
如果当前没有可展示插件，帮助文档会返回“当前暂无可展示插件文档”。
