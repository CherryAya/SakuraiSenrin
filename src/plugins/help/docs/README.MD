# 帮助文档

## 概览
你也好奇凛凛的技能树点在了什么奇怪的地方上吧（笑）

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- Help: `help`
- 别名: 总表, 列表
- 指令: `#help [插件名] [子功能名]`
- Demo: help-main.webp
## 说明
可以这样用：

- `#help 图片搜索`：直接看某个插件说明
- `#help 管理模块总览 group`：先进总览，再定位到子模块
- 插件总览会按功能分开发送：
  先给出 `👉 功能名` 和可直接复制的命令，再插入对应示例图
- 最后一张图只保留这个插件的简介、反馈方式和交流群入口

## 完整流程
```demo
USER: #help
BOT: [展示帮助文档]
USER: #help 图片搜索
BOT: [直接展示搜图功能说明和 demo]
USER: #help 管理模块总览 group
BOT: [按功能依次发送命令和 demo，最后补一张模块简介图]
USER: #help 群组管理模块 ban
```
