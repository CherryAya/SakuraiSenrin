# 帮助中心

## 概览
统一汇总项目内插件文档，并支持按插件名或子功能名继续深入查询。用户先看插件目录，再按功能查看完整流程和 demo 图。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `index` 插件索引: 查看当前可见插件列表与分类。
- `plugin-detail` 插件详情: 查看某个插件的总览、权限与子功能目录。
- `feature-detail` 子功能详情: 查看某个子功能的完整使用流程和 demo 图。

## 子功能详情
### `index` 插件索引
- 摘要: 查看当前可见插件列表与分类。
- 别名: 总表, 列表
- 指令: `#help`
- Demo: help-index.png
#### 说明
不带参数发送 `#help` 时，帮助中心会返回按分类整理后的插件列表。这个列表只展示 `visible=True` 的插件。
#### 前置条件
机器人已正常启动，并至少加载了一个带 `extra.docs` 的项目插件。
#### 完整流程
先查看索引，再决定深入哪个插件。
```demo
USER: #help
BOT: ===== 插件帮助索引 =====
[core]
- 帮助中心: 统一汇总插件文档，并按插件 metadata.docs 自动注册。
[fun]
- 吹水记录: 群聊活跃记录、画像、榜单与活动赛季。
```
#### 失败情况
如果当前没有可展示插件，帮助中心会返回“当前暂无可展示插件文档”。

### `plugin-detail` 插件详情
- 摘要: 查看某个插件的总览、权限与子功能目录。
- 别名: 插件文档, 详情
- 指令: `#help <插件名>`
- Demo: help-plugin-detail.png
#### 说明
当用户明确指定插件名后，帮助中心会返回该插件的总览信息，并列出可继续查询的子功能 slug。
#### 前置条件
需要提供一个能够命中的插件名、模块名或插件别名。
#### 完整流程
先定位插件，再决定查看哪个子功能。
```demo
USER: #help 吹水记录
BOT: ===== 吹水记录 =====
触发方式: 指令触发
权限: 普通用户
子功能目录:
- profile (查看个人画像)
```
#### 失败情况
如果插件名不存在，会提示先发送 `#help` 查看总表；如果命中多个插件，会返回候选列表。

### `feature-detail` 子功能详情
- 摘要: 查看某个子功能的完整使用流程和 demo 图。
- 别名: 子功能, 功能详情
- 指令: `#help <插件名> <子功能名>`
- Demo: help-feature-detail.png
#### 说明
当用户继续补充子功能名后，帮助中心会返回该功能的文字说明、前置条件、失败情况，并附上一张完整对话流程图。
#### 前置条件
插件名必须先能命中，子功能名需要命中 README 中定义的 slug、标题或别名。
#### 完整流程
推荐先看插件详情，再精确查询子功能。
```demo
USER: #help 吹水记录 ranking
BOT: ===== 吹水记录 / 查看周期榜单 =====
说明: 选择周榜、月榜、季榜、年榜或总榜查看排行。
[附带一张完整 demo 图]
```
#### 失败情况
如果子功能名不存在，会提示“未找到子功能文档”；如果命中多个子功能，会返回歧义候选。
