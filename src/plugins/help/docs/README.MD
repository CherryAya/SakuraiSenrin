# 帮助文档

## 概览
你也好奇凛凛的技能树点在了什么奇怪的地方上吧（笑）

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- Help: `help`
- 别名: 总表, 列表
- 指令: `#help [插件名] [子功能名]`
- Demo: help-index.png
## 说明
什么？！那就让凛凛手把手教你怎么用吧！要跟上哦？

## 前置条件
无。

## 完整流程
```demo
USER: #help
BOT: [展示帮助文档]
USER: #help 图片搜索
BOT: [直接展示搜图功能说明和 demo]
USER: #help 管理模块总览 group
BOT: [展示群组管理模块详情]
USER: #help 群组管理模块 ban
```

## 失败情况
当查询的插件名或子功能不存在时，帮助系统会返回未命中或歧义提示，而不是对应图片。
