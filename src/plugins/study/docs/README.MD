# 词库模块（传统版）

## 概览
`study` 就一个功能：往词库里学习一条触发词和响应词。常用法只有两种：

1. 直接命令式输入：`#study <a|m> <t|f> trigger response`
2. 只发 `#study` 进入引导式模式，按提示补全参数

无论走哪条路径，最终都会把词条提交到 `wordbank` 审核；审核通过前不会参与被动匹配。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- Help: `study`
- 别名: study, 学习
- 指令: `study`；快捷入口分组: 直接命令: `study <a|m> <t|f> 触发词 响应词` / `study 触发词 => 响应词`；引导模式: `study`；中断: `revoke` / `recall`
- Demo: study-collection.png

## 说明
### 直接命令式
支持两套写法：

- 传统参数式：`study <a|m> <t|f> 触发词 响应词`
- 快捷分隔式：`study 触发词 => 响应词`

参数含义如下：

- `a`: 对所有人有效
- `m`: 仅对自己有效
- `t`: 开启群组隔离，仅当前群聊有效
- `f`: 关闭群组隔离，按触发方式跨群或私聊生效

范围映射：

- `a + t`: 对所有人有效，但仅当前群可触发
- `a + f`: 对所有人有效，并按场景扩展到跨群或私聊
- `m + t`: 仅创建者自己在当前群可触发
- `m + f`: 仅创建者自己可触发，不限当前群或私聊

支持 `=>`、`->`、`回答`、`回复` 分隔触发词和响应词。命令里可以直接带图片：

- `study 触发词 [图片]`: 文本触发、图片回复
- `study [图片] => 响应词`: 图片触发、文本回复
- `study 触发词 => 响应词 [图片]`: 文本触发、图文回复

### 引导式模式
不带参数发送 `study` / `学习` 时，会按顺序引导你输入：

1. 触发方式：`a` 或 `m`
2. 群组隔离：`t` 或 `f`
3. 触发词
4. 响应词
5. 权重（1 到 5，直接发 `3` 可用默认值）

触发词和响应词步骤都支持直接发送图片。

### 中断与回退
引导过程中输入 `revoke` 或 `recall` 会直接取消当前会话。

如果平台本身触发了真实撤回：

- 撤回最初发出的 `#study`：整段会话取消
- 撤回最近一步成功输入：回退到当前步骤重做
- 撤回更早的旧步骤消息：无效

### 审核与结果
添加完成后词条状态为 `pending`，管理员通过前不会触发。具体审核流程请查看 `#help 词库审核`。

## 前置条件
当前用户所在会话需要通过运行时检查；图片场景下，消息里的图片需要可下载、可识别。

## 失败情况
以下情况会返回格式说明或具体原因：

- 旧版 `a/m t/f` 参数不完整、顺序错误或内容缺失
- 缺少触发词或响应词
- 任一步引导输入为空或格式无效
- 连续输错 3 次，被强制终止对话
- 图片下载失败或图片无法识别，此时不会写入词库
