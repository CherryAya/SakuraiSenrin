# 学习模块

## 概览
学习模块保留传统 `study` / `学习` 快捷入口，用于把简单文本词条加入 `wordbank`。不带参数时会进入五步引导；引导任一步收到 `revoke` / `recall` 会直接中止，不发送取消提示。它不维护独立数据库、规则或运行时索引；查询、删除、投票删除、恢复、图片词条、回复式词条管理和被动匹配都由 `wordbank` 负责。完整管理命令请使用 `wordbank add/search/delete/support/vote/restore/image`，也兼容旧式 `wordbank.add`、`wordbank.search`、`wordbank.delete`、`wordbank.support`、`wordbank.vote`、`wordbank.restore`、`wordbank.image` 入口。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `shortcut` 快捷学习: 兼容旧学习格式并转换为 wordbank 固定规则；无参数时进入五步引导。

## 子功能详情
### `shortcut` 快捷学习
- 摘要: 使用旧式简短命令添加词库。
- 别名: study, 学习
- 指令: `study 触发词 => 响应词`
- 兼容指令: `study <a|m> <t|f> 触发词 响应词`
#### 说明
支持 `=>`、`->`、`回答`、`回复` 分隔触发词和响应词。也兼容旧版一键格式：`a` 表示对所有人有效，`m` 表示仅对自己有效；`t` 表示开启群组隔离，`f` 表示关闭群组隔离。不带参数发送 `study` / `学习` 时会进入五步引导：触发方式 -> 群组隔离 -> 触发词 -> 响应词 -> 权重。内部会调用 `wordbank add` 使用的固定规则模型，默认群聊范围为当前群，私聊范围为本人。引导任一步收到 `revoke` / `recall` 会直接中止，不发送取消提示。需要搜索、删除、投票删除、恢复、回复机器人自动回复查看详情或添加图片词条时请使用 `wordbank` 命令；中文直达入口 `添加词条`、`搜索词条`、`删除词条`、`支持删除`、`查看投票状态`、`恢复词条`、`图片词条` 也会转入对应新版子命令。
#### 前置条件
当前用户所在群聊需要通过运行时检查。
#### 完整流程
```demo
USER: #study
BOT: 请选择触发方式：
a. 对所有人有效
m. 仅对自己有效
USER: a
BOT: 是否开启群组隔离？
t. 开启，仅当前群聊有效
f. 关闭，按触发方式跨群或私聊生效
USER: t
BOT: 请输入触发词：
USER: 晚安
BOT: 请输入响应词：
USER: 做个好梦
BOT: 请输入响应词权重，1-5 之间的数字；直接发送 3 可用默认权重：
USER: 3
BOT: 词条已加入词库
ID: 12
触发: 晚安
响应: 做个好梦
模式: contains
范围: current_group
概率: 1
权重: 3
USER: 大家晚安啦
BOT: 做个好梦
```
#### 失败情况
缺少触发词或响应词、旧版 `a/m t/f` 参数不完整时返回格式说明；引导任一步检测到 `revoke` / `recall` 会直接中止，不发送取消提示。
