# 学习模块

## 概览
学习模块保留传统 `study` / `学习` 快捷入口，用于把常用词条提交到 `wordbank`。它不维护独立数据库、规则或运行时索引；查询、审核、删除、投票删除、恢复、回复式词条管理和被动匹配都由 `wordbank` 负责。你可以把它理解成“面向快速录入的薄包装层”：直接命令、五步引导、图片解析和撤回回退都在这里完成，真正的词条规则仍落到 `wordbank`。如果你需要完整参数和规则视角，请查看 `#help 词库模块`；如果你要看审核流程，请查看 `#help 词库审核`。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `shortcut` 基础快捷学习: 最常见的 `study 触发词 => 响应词` 用法。
- `legacy-args` 旧版参数映射: `a / m / t / f` 的语义和范围对应。
- `guided-flow` 五步引导: 不带参数时的交互流程。
- `image-cases` 图片场景: 图片触发、图片回复、图文混排。
- `recall-rewind` 撤回与回退: 手动 `revoke` / `recall` 取消，以及真实撤回消息的回退边界。

## 子功能详情
### `shortcut` 基础快捷学习
- 摘要: 用最短命令把词条提交到 wordbank。
- 别名: study, 学习
- 指令: `study 触发词 => 响应词`
- 兼容指令: `study 触发词 [图片]`、`study [图片] => 响应词`
- Demo: study-shortcut.png
#### 说明
支持 `=>`、`->`、`回答`、`回复` 分隔触发词和响应词。直接命令里附带图片时会复用 `wordbank add` 的媒体分流：`study 触发词 [图片]` 表示文本触发、图片回复；`study 触发词 => 响应词 [图片]` 表示文本触发、图文回复；`study [图片] => 响应词` 表示图片触发、文本回复。内部会调用 `wordbank add` 使用的固定规则模型，默认群聊范围为当前群，私聊范围为本人。添加完成后词条状态为 `pending`，审核通过前不会参与被动匹配；具体审核流程请查看 `#help 词库审核`。
#### 常用示例命令
- `#study 晚安 => 做个好梦`
- `#study 晚安 [图片]`
- `#study [图片] => 这张图我记住了`
- `#study 晚安 => 做个好梦 [图片]`
#### 前置条件
当前用户所在群聊需要通过运行时检查。
#### 完整流程
```demo
USER: #study 晚安 => 做个好梦
BOT: 词条已提交审核
ID: 12
状态: pending
触发: 晚安
响应: 做个好梦
模式: contains
范围: current_group
概率: 1
权重: 3
管理员通过前不会触发。
SYSTEM: 这条词条已进入 wordbank，详细审核流程请查看 #help 词库审核。
USER: #study 是这张图喔 [图片]
BOT: 词条已提交审核
ID: 13
状态: pending
触发: 是这张图喔
响应: [图片:7]
模式: contains
范围: current_group
概率: 1
权重: 3
管理员通过前不会触发。
USER: #study [图片] => 是这张图喔
BOT: 词条已提交审核
ID: 14
状态: pending
触发: [图片:7]
响应: 是这张图喔
模式: fullmatch
范围: current_group
概率: 1
权重: 3
管理员通过前不会触发。
```
#### 失败情况
缺少触发词或响应词、图片下载失败或图片无法识别时返回格式说明或具体原因。

### `legacy-args` 旧版参数映射
- 摘要: 说明 `a / m / t / f` 旧版参数如何映射到新版规则。
- 别名: a, m, t, f, 旧参数, 范围映射
- 指令: `study <a|m> <t|f> 触发词 响应词`
- 兼容指令: `study <a|m> <t|f> [图片] [图片]`
- Demo: study-legacy-args.png
#### 说明
`a` 表示对所有人有效，`m` 表示仅对自己有效；`t` 表示开启群组隔离，`f` 表示关闭群组隔离。最终会转换成新版 scope 规则：
- `a + t`: 对所有人有效，但仅当前群可触发。
- `a + f`: 对所有人有效，并按场景扩展到跨群或私聊。
- `m + t`: 仅创建者自己在当前群可触发。
- `m + f`: 仅创建者自己可触发，不限当前群或私聊。
#### 常用示例命令
- `#study a t 晚安 做个好梦`
- `#study a f 群公告 大家记得看`
- `#study m t 只有我能触发 这是我的提醒`
- `#study m f 私聊也能触发 这是我的全局提醒`
- `#study a f [图片] [图片]`
#### 前置条件
需要按顺序提供两个旧版参数，再提供触发与响应内容。
#### 完整流程
```demo
USER: #study a f 群公告 大家记得看
SYSTEM: `a` 表示对所有人有效，`f` 表示关闭群组隔离，因此会映射到更宽范围。
BOT: 词条已提交审核
ID: 15
状态: pending
触发: 群公告
响应: 大家记得看
模式: contains
范围: all_groups
概率: 1
权重: 3
管理员通过前不会触发。
USER: #study m t 只有我能触发 这是我的提醒
SYSTEM: `m` 表示仅自己有效，`t` 表示只限当前群，因此会映射到 self_in_current_group。
BOT: 词条已提交审核
ID: 16
状态: pending
触发: 只有我能触发
响应: 这是我的提醒
模式: contains
范围: self_in_current_group
概率: 1
权重: 3
管理员通过前不会触发。
```
#### 失败情况
旧版 `a/m t/f` 参数不完整、顺序错误或内容缺失时会返回格式说明。

### `guided-flow` 五步引导
- 摘要: 不带参数时进入五步交互式学习流程。
- 别名: 引导, 五步引导, 交互式学习
- 指令: `study`
- 兼容指令: `学习`
- Demo: study-guided-flow.png
#### 说明
不带参数发送 `study` / `学习` 时会进入五步引导：触发方式 -> 群组隔离 -> 触发词 -> 响应词 -> 权重。触发词步骤可直接发送图片作为图片触发，响应词步骤可发送图片作为图片回复。权重范围是 1 到 5，直接发送 `3` 可用默认权重。
#### 常用示例命令
- `#study`
- `#学习`
#### 前置条件
需要按顺序完成引导步骤。
#### 完整流程
```demo
USER: #study
BOT: 请选择触发方式：
a. 对所有人有效
m. 仅对自己有效
USER: a
BOT: 是否开启群组隔离？
t. 开启，仅当前群聊有效
f. 关闭，按触发方式跨群或私聊生效
USER: t
BOT: 请输入触发词，或直接发送图片作为图片触发：
USER: 晚安
BOT: 请输入响应词，或发送图片作为图片回复：
USER: 做个好梦
BOT: 请输入响应词权重，1-5 之间的数字；直接发送 3 可用默认权重：
USER: 3
BOT: 词条已提交审核
ID: 17
状态: pending
触发: 晚安
响应: 做个好梦
模式: contains
范围: current_group
概率: 1
权重: 3
管理员通过前不会触发。
```
#### 失败情况
任一步输入为空或格式无效时会提示重输；连续输错 3 次会强制终止对话。

### `image-cases` 图片场景
- 摘要: 说明图片触发、图片回复和图文混排的不同写法。
- 别名: 图片触发, 图片回复, 图文混排
- 指令: `study 触发词 [图片]`
- 兼容指令: `study [图片] => 响应词`、`study 触发词 => 响应词 [图片]`
- Demo: study-image-cases.png
#### 说明
`study 触发词 [图片]` 表示文本触发、图片回复；`study [图片] => 响应词` 表示图片触发、文本回复；`study 触发词 => 响应词 [图片]` 表示文本触发、图文混排回复。引导模式收到图片后会在后台下载并自动重试，用户可继续完成后续配置；最终仍无法下载或识别时，会提示词条设置失败且不写入词库。
#### 常用示例命令
- `#study 晚安 [图片]`
- `#study [图片] => 这是这张图`
- `#study 晚安 => 做个好梦 [图片]`
- `#study a f [图片] [图片]`
#### 前置条件
消息里需要包含可下载、可识别的图片。
#### 完整流程
```demo
USER: #study
BOT: 请选择触发方式：
a. 对所有人有效
m. 仅对自己有效
USER: a
BOT: 是否开启群组隔离？
t. 开启，仅当前群聊有效
f. 关闭，按触发方式跨群或私聊生效
USER: t
BOT: 请输入触发词，或直接发送图片作为图片触发：
USER: [发送图片]
BOT: 请输入响应词，或发送图片作为图片回复：
USER: 做个好梦
BOT: 请输入响应词权重，1-5 之间的数字；直接发送 3 可用默认权重：
USER: 3
BOT: 还有 1 张图片正在处理中，请稍等。
BOT: 词条已提交审核
ID: 18
状态: pending
触发: [图片:8]
响应: 做个好梦
模式: fullmatch
范围: current_group
概率: 1
权重: 3
管理员通过前不会触发。
```
#### 失败情况
图片下载失败或图片无法识别时会返回具体原因，不会写入词库。

### `recall-rewind` 撤回与回退
- 摘要: 说明手动取消和真实撤回消息的回退边界。
- 别名: revoke, recall, 撤回, 回退, 重做当前步骤
- 指令: 引导中输入 `revoke` / `recall`
- 兼容指令: 撤回真实聊天消息
- Demo: study-recall-rewind.png
#### 说明
手动输入 `revoke` / `recall` 会直接取消整段引导。真实消息撤回时，撤回 `#study` 会取消整段会话；撤回最近一步成功输入只会重做当前步骤；跨步骤撤回旧消息无效。群聊和私聊分别兼容 `group_recall` / `friend_recall`。这个回退逻辑只作用于当前活跃引导会话，不会影响已提交完成的词条。
#### 常用示例命令
- `study` 引导中直接发送 `revoke`
- `study` 引导中直接发送 `recall`
- 撤回刚刚输入的当前步骤消息
- 撤回最初发出的 `#study`
#### 前置条件
需要当前仍处于 `study` 引导会话中。
#### 完整流程
```demo
USER: #study
BOT: 请选择触发方式：
a. 对所有人有效
m. 仅对自己有效
USER: a
BOT: 是否开启群组隔离？
t. 开启，仅当前群聊有效
f. 关闭，按触发方式跨群或私聊生效
USER: [撤回刚才输入的“a”]
BOT: 请选择触发方式：
a. 对所有人有效
m. 仅对自己有效
USER: a
BOT: 是否开启群组隔离？
t. 开启，仅当前群聊有效
f. 关闭，按触发方式跨群或私聊生效
USER: [撤回最初发送的“#study”]
BOT: 本次操作已被取消。
SYSTEM: 如果撤回的是更早的旧步骤消息，而不是最近一步成功输入，则不会起作用。
```
#### 失败情况
手动输入 `revoke` / `recall` 会发送取消提示并中止；真实撤回消息时仅支持取消整段或重做最近一步，连续输错 3 次也会强制终止对话。
