# 学习模块

## 概览
学习模块保留传统 `study` / `学习` 快捷入口，用于把常用词条提交到 `wordbank`。不带参数时会进入五步引导；手动输入 `revoke` / `recall` 会直接取消当前引导，连续输错 3 次也会终止。真实消息撤回时，撤回 `#study` 会取消整段会话，撤回最近一步成功输入会重做当前步骤，跨步骤撤回旧消息无效，群聊和私聊分别兼容 `group_recall` / `friend_recall`。它不维护独立数据库、规则或运行时索引；查询、审核、删除、投票删除、恢复、回复式词条管理和被动匹配都由 `wordbank` 负责。添加成功后会进入 `pending`，私聊超级用户发送审批通知，并记录提交回执消息；管理员可直接回复审批通知或提交回执并 @ 机器人发送 `y` / `n` 一键通过或驳回。图片回复、图文回复和图片触发也复用 `wordbank add` 的媒体处理逻辑。完整管理命令请使用 `wordbank add/search/pending/approve/reject/delete/support/vote/restore`，也兼容旧式 `wordbank.add`、`wordbank.search`、`wordbank.pending`、`wordbank.approve`、`wordbank.reject`、`wordbank.delete`、`wordbank.support`、`wordbank.vote`、`wordbank.restore` 入口。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `shortcut` 快捷学习: 兼容旧学习格式并转换为 wordbank 固定规则；直接命令和五步引导均可解析图片。

## 子功能详情
### `shortcut` 快捷学习
- 摘要: 使用旧式简短命令添加词库。
- 别名: study, 学习
- 指令: `study 触发词 => 响应词`
- 兼容指令: `study 触发词 [图片]`、`study [图片] => 响应词`、`study <a|m> <t|f> 触发词 响应词`、`study <a|m> <t|f> [图片] [图片]`
#### 说明
支持 `=>`、`->`、`回答`、`回复` 分隔触发词和响应词。也兼容旧版一键格式：`a` 表示对所有人有效，`m` 表示仅对自己有效；`t` 表示开启群组隔离，`f` 表示关闭群组隔离。直接命令里附带图片时会复用 `wordbank add` 的媒体分流：`study 触发词 [图片]` 表示文本触发、图片回复；`study 触发词 => 响应词 [图片]` 表示文本触发、图文回复；`study [图片] => 响应词` 表示图片触发、文本回复；`study a f [图片] [图片]` 会保留旧版作用范围参数，并把第一张图片作为触发、第二张图片作为回复。不带参数发送 `study` / `学习` 时会进入五步引导：触发方式 -> 群组隔离 -> 触发词 -> 响应词 -> 权重；触发词步骤可直接发送图片作为图片触发，响应词步骤可发送图片作为图片回复。引导模式收到图片后会在后台下载并自动重试，用户可继续完成后续配置；最终仍无法下载或识别时，会提示词条设置失败且不写入词库。提交前如果仍有图片在后台处理，会先提示剩余处理数量再等待最终结果。内部会调用 `wordbank add` 使用的固定规则模型，默认群聊范围为当前群，私聊范围为本人。添加完成后词条状态为 `pending`，管理员审核通过前不会参与被动匹配；系统会向超级用户发送审批私聊并记录提交回执，回复对应消息并 @ 机器人发送 `y` / `approve` / `通过` 可一键通过，发送 `n` / `reject` / `拒绝` 可一键驳回。手动输入 `revoke` / `recall` 会直接取消整段引导；真实消息撤回时，撤回 `#study` 会取消整段会话，撤回最近一步成功输入只会重做当前步骤，跨步骤撤回旧消息无效。搜索、审核、删除、投票删除、恢复和回复机器人自动回复查看详情仍使用 `wordbank` 管理命令；中文直达入口 `添加词条`、`搜索词条`、`待审核词条`、`通过词条`、`拒绝词条`、`删除词条`、`支持删除`、`查看投票状态`、`恢复词条` 也会转入对应新版子命令。
#### 旧版参数解释
- `a`
  对所有人有效。群聊里通常映射到更广作用范围，私聊里也允许其他私聊命中。
- `m`
  仅对自己有效。最终会落到 `self` 或 `self_in_current_group` 一类更窄范围。
- `t`
  开启群组隔离。群聊里表示只在当前群有效。
- `f`
  关闭群组隔离。范围由 `a` / `m` 决定，可能扩展到所有群、所有私聊或“自己在任意场景”。
#### 常用示例命令
- `#study 晚安 => 做个好梦`
- `#study 早 [图片]`
- `#study [图片] => 这张图我记住了`
- `#study 晚安 => 做个好梦 [图片]`
- `#study a t 晚安 做个好梦`
- `#study a f 群公告 大家记得看`
- `#study m t 只有我能触发 这是我的提醒`
- `#study m f 私聊也能触发 这是我的全局提醒`
- `#study a f [图片] [图片]`
- `#study`
#### 作用范围速记
- `a + t`
  对所有人有效，但仅当前群可触发。
- `a + f`
  对所有人有效，并按场景扩展到跨群或私聊。
- `m + t`
  仅创建者自己在当前群可触发。
- `m + f`
  仅创建者自己可触发，不限当前群或私聊。

当前用户所在群聊需要通过运行时检查。

#### 失败情况
缺少触发词或响应词、旧版 `a/m t/f` 参数不完整、图片下载失败或图片无法识别时返回格式说明或具体原因；手动输入 `revoke` / `recall` 会发送取消提示并中止，真实撤回消息时仅支持取消整段或重做最近一步，连续输错 3 次会强制终止对话。
