# 学习模块

## 概览
学习模块保留传统 `study` 快捷入口，用于把简单文本词条加入 `wordbank`。它不维护独立数据库、规则或运行时索引；查询、删除、恢复、图片词条和被动匹配都由 `wordbank` 负责。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `shortcut` 快捷学习: 兼容旧学习格式并转换为 wordbank 固定规则。

## 子功能详情
### `shortcut` 快捷学习
- 摘要: 使用旧式简短命令添加词库。
- 别名: study, 学习
- 指令: `study 触发词 => 响应词`
- Demo: study-placeholder.png
#### 说明
支持 `=>`、`->`、`回答`、`回复` 分隔触发词和响应词。内部会调用 `wordbank add` 使用的固定规则模型，默认群聊范围为当前群，私聊范围为本人。需要搜索、删除、恢复或添加图片词条时请使用 `wordbank` 命令。
#### 前置条件
当前用户所在群聊需要通过运行时检查。
#### 完整流程
```demo
USER: #study 晚安 => 做个好梦
BOT: 词条已加入词库
```
#### 失败情况
缺少触发词或响应词时返回格式说明；撤回类 `revoke` / `recall` 信号由 `wordbank` 被动匹配入口直接跳过。
