# 词库模块（传统版）

## 概览
牢玩家最喜欢的 #study a f

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 用法
- Help: `study`
- 别名: study, 学习
- 指令: `#study <a|m> <t|f> 触发词 响应词`
- Demo: study-main.webp

## 说明
> [!TIP]
> 传统参数式：`#study <a|m> <t|f> 触发词 响应词`
>
> 参数含义如下：
>
> - `a`: 对所有人有效
> - `m`: 仅对自己有效
> - `t`: 开启群组隔离，仅当前群聊有效
> - `f`: 关闭群组隔离，按触发方式跨群或私聊生效

> [!TIP]
> 快捷分隔式：`#study 触发词 => 响应词`
>
> 这是日常最省脑子的写法，适合只想快速教一条文本词条的时候直接录入。
>
> 如果你还想控制生效范围，就回到上面的传统参数式。

> [!TIP]
> 如果你是第一次用事件词条，优先记这些更直观的入口就够了：
>
> - `[@]` / `【@】` / `[at]` / `【at】`：凛凛被 `@`
> - `[提及]` / `【提及】`：凛凛被提及
> - `[戳一戳]` / `【戳一戳】`：凛凛被戳一戳
> - `[新人加入]` / `【新人加入】` / `[新成员加入]` / `【新成员加入】` / `[有人加群]` / `【有人加群】`：有人进群
> - `[成员退群]` / `【成员退群】` / `[有人退群]` / `【有人退群】` / `[离群]` / `【离群】`：有人退群
>
> 如果你已经熟悉结构化写法，也兼容标准事件名：
>
> - `event:at`
> - `event:mention`
> - `event:poke`
> - `event:join` / `event:group_join` / `event:group_increase`
> - `event:leave` / `event:group_leave` / `event:group_decrease`
>
> 事件解析只作用于触发词；响应词中的 `event:*` 会按普通文本原样保存和发送。
>
> 如果你要录入字面量文本 `[戳一戳]`、`【新人加入】` 或 `event:poke`，请在前面加 `\`，例如 `\[戳一戳]`、`\event:poke`；如果要保留开头那个反斜杠本身，再写成 `\\[戳一戳]`、`\\event:poke`。

> [!TIP]
> 引导模式：`study` / `学习`
>
> 不带参数直接发送时，凛凛会按顺序一步一步问你，适合不想记参数、或者准备慢慢确认配置的时候使用。
>
> 引导过程中输入 `revoke` / `recall` / `exit` 会直接取消当前会话。

> [!TIP]
> 撤回规则
>
> 如果此时撤回自己发送的消息时：
>
> - 撤回最初发出的 `#study`：整段会话取消
> - 撤回最近一步成功输入：回退到当前步骤重做
> - 撤回更早的旧步骤消息：无效
>
> 手动输入 `revoke/recall/exit` 是“整段取消”，真实撤回最近一步消息才是“只回退当前步骤”。

## 前置条件
词条需要通过审核后才会触发

## 失败情况
连续输错 3 次，被强制终止对话
图片下载失败或图片无法识别，此时不会写入词库
