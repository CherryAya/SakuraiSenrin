# 测试模块

## 概览
测试模块主要给开发环境挂 matcher、验事件链路，或者做一点临时行为实验用，不是给普通用户直接玩的功能呢。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 用法
- Help: `test`
- 别名: 调试, matcher
- 指令: 被动触发
- Demo: test-listener.png
## 说明
这个 matcher 本身不负责业务处理，主要就是在开发或测试阶段先占住一个事件入口。
## 前置条件
通常只建议在开发环境里使用，不太适合在生产环境里拿它承载正式用户功能哦。
## 完整流程
事件经过时 matcher 会被触发，不过它不会额外给用户发消息。
```demo
USER: 随便发一条测试消息
SYSTEM: test matcher 收到事件，未向用户输出内容。
```
## 失败情况
如果以后有人把业务逻辑塞进这个模块，文档和测试就都得一起升级，不能再把它当成空壳监听器来看啦。
