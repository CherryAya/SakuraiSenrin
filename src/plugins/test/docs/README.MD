# 测试模块

## 概览
测试模块仅用于开发环境挂载 matcher、验证事件链路或做临时行为实验，不面向普通用户开放。

## 权限与触发
- 触发方式: 被动触发
- 权限: 超级管理员

## 用法
- 别名: 调试, matcher
- 指令: 被动触发
- Demo: test-listener.png
## 说明
这个 matcher 本身不处理业务，只负责在开发或测试时占住一个事件入口。
## 前置条件
通常只应在开发环境使用，不建议在生产环境依赖它承载任何用户功能。
## 完整流程
事件经过时 matcher 被触发，但不会输出额外消息。
```demo
USER: 随便发一条测试消息
SYSTEM: test matcher 收到事件，未向用户输出内容。
```
## 失败情况
如果有人把业务逻辑偷偷塞进这个模块，文档和测试都需要同步升级，不应继续把它视作空壳监听器。
