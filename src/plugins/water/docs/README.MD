# Water

## 用法

- `水王`
  个人画像（简版）
- `水王 完整`
  个人画像（完整版）
- `水王 日榜 / 月榜 / 季榜 / 年榜 / 总榜`
- `水王 成就`
- `水王 赛季`
  当前活动赛季概览
- `水王 赛季 当前`
- `水王 赛季 列表`
- `水王 赛季 当前列表`
- `水王 赛季 <season_id|名称> [个人|群聊|矩阵] [概览|积分|排名|成就]`

## 管理

- `#water season create <season_id> <start> <end> <name...>`
- `#water season publish <season_id>`
- `#water season archive <season_id>`
- `#water season show <season_id>`
- `#water season list [current|published|archived]`
- `#water season delete <season_id>`
