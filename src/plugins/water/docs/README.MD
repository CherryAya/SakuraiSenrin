# 吹水记录

## 概览
吹水记录插件负责记录群聊活跃度，并提供个人画像、周期榜单、成就系统、活动赛季、矩阵合并建议以及一组仅超管可用的维护命令。

## 权限与触发
- 触发方式: 指令触发
- 权限: 普通用户

## 子功能目录
- `profile` 查看个人画像: 查询 `#我有多水`。
- `profile-full` 查看完整画像: 查询 `#我有多水 完整`。
- `ranking` 查看自然榜单: 查询 `#水王 <主体> <范围> <时间>`。
- `today-report` 查看今日群报告: 群管理发送 `#水王 今日报告` 或 `#水王日报`。
- `achievement` 查看个人成就: 查询当前已解锁与下一步成就。
- `season-query` 查看赛季数据: 查询赛季概览、积分、排名与成就视图。
- `merge-confirm` 处理矩阵合并建议: 群管理员对智能建议发送 `#water.merge yes/no`。
- `admin-maintenance` 超管维护命令: 超管执行结算、回档、忽略、状态与赛季管理。

## 子功能详情
### `profile` 查看个人画像
- 摘要: 查询默认个人画像。
- 别名: 我有多水, 画像
- 指令: `#我有多水`
- Demo: water-profile.png
#### 说明
直接发送 `#我有多水` 会查询当前用户在当前群的个人画像简版。
#### 前置条件
需要在群聊中使用，且当前用户已有足够统计数据。
#### 完整流程
默认不带参数时走个人画像查询。
```demo
USER: #我有多水
BOT: [发送个人画像图片]
```
#### 失败情况
如果当前不在群聊里，会提示“这个命令要在群里用”；如果数据不足，会提示先多聊几天。

### `profile-full` 查看完整画像
- 摘要: 查询完整版个人画像。
- 别名: 完整画像, full
- 指令: `#我有多水 完整`
- Demo: water-profile-full.png
#### 说明
在 `#我有多水` 后补上 `完整`，会返回信息量更高的完整版画像。
#### 前置条件
需要在群聊中使用，并且用户已有可用画像数据。
#### 完整流程
输入 `完整` 关键字即可切换模式。
```demo
USER: #我有多水 完整
BOT: [发送完整版个人画像图片]
```
#### 失败情况
如果画像生成失败，帮助文档需要与实际渲染逻辑一起排查。

### `ranking` 查看周期榜单
- 摘要: 按 主体 + 范围 + 时间 查询自然榜单。
- 别名: 榜单
- 指令: `#水王` / `#水王 <主体> <范围> <时间>`
- Demo: water-ranking.png
#### 说明
自然榜单已改为三维模型：
- 主体: `用户榜 / 群聊榜 / 矩阵榜`
- 范围: `本群 / 本矩阵 / 全局`
- 时间: `日榜 / 周榜 / 月榜 / 季榜`

单发 `#水王` 不直接查榜，而是进入三步引导：主体 -> 范围 -> 时间。引导提示保持短句式，并与 `study` 一致支持手动 `revoke / recall` 取消。

另外所有“当前可见合法组合”都补了快捷入口，命中后会直接展开成固定三维组合：
- `用户榜 / 本群`: `#今日水王` / `#本周水王` / `#本月水王` / `#本季水王`
- `用户榜 / 本矩阵`: `#今日矩阵水王` / `#本周矩阵水王` / `#本月矩阵水王` / `#本季矩阵水王`
- `用户榜 / 全局`: `#今日全局水王` / `#本周全局水王` / `#本月全局水王` / `#本季全局水王`
- `群聊榜 / 本矩阵`: `#今日矩阵群榜` / `#今日矩阵群聊榜` / `#本周矩阵群榜` / `#本周矩阵群聊榜` / `#本月矩阵群榜` / `#本月矩阵群聊榜` / `#本季矩阵群榜` / `#本季矩阵群聊榜`
- `群聊榜 / 全局`: `#今日群榜` / `#今日群聊榜` / `#本周群榜` / `#本周群聊榜` / `#本月群榜` / `#本月群聊榜` / `#本季群榜` / `#本季群聊榜`
- `矩阵榜 / 全局`: `#今日矩阵榜` / `#本周矩阵榜` / `#本月矩阵榜` / `#本季矩阵榜`
#### 前置条件
需要在群聊中使用，并且对应组合已有实时或结算数据。
#### 完整流程
帮助文档推荐顺序固定为 `主体 范围 时间`，解析层允许任意顺序。
```demo
USER: #水王
BOT: 请选择榜单主体：用户榜 / 群聊榜 / 矩阵榜
BOT: 发送 revoke / recall 可取消，连续输错 3 次会自动退出。
USER: 用户榜
BOT: 请选择范围：本群 / 本矩阵 / 全局
BOT: 发送 revoke / recall 可取消，连续输错 3 次会自动退出。
USER: 本群
BOT: 请选择时间：日榜 / 周榜 / 月榜 / 季榜
BOT: 发送 revoke / recall 可取消，连续输错 3 次会自动退出。
USER: 月榜
BOT: [发送用户榜 · 本群月榜图片]
USER: #水王 用户榜 本群 月榜
BOT: [发送用户榜 · 本群月榜图片]
USER: #水王 群聊榜 本矩阵 周榜
BOT: [发送群聊榜 · 本矩阵周榜图片]
USER: #今日水王
BOT: [发送用户榜 · 本群日榜图片]
USER: #今日矩阵水王
BOT: [发送用户榜 · 本矩阵日榜图片]
USER: #今日全局水王
BOT: [发送用户榜 · 全局日榜图片]
USER: #本周矩阵群榜
BOT: [发送群聊榜 · 本矩阵周榜图片]
USER: #本周群榜
BOT: [发送群聊榜 · 全局周榜图片]
```
#### 失败情况
缺少任一维度时会继续引导补全；非法组合会给出合法替代示例并停留在当前步骤；时间维度只接受当前菜单中的合法选项。快捷入口不接受额外参数，多带内容会提示直接发送原快捷命令。引导过程中手动输入 `revoke` / `recall` 会直接取消，真实撤回根消息会中止整段会话，连续输错 3 次会强制退出。

#### 合法组合
- `用户榜`: `本群 / 本矩阵 / 全局`
- `群聊榜`: `本矩阵 / 全局`
- `矩阵榜`: `全局`

#### 非法组合示例
- `#水王 群聊榜 本群 月榜`
- `#水王 矩阵榜 本矩阵 季榜`

### `today-report` 查看今日群报告
- 摘要: 群管理主动拉取当前群当天实时报告。
- 别名: 水王日报, 今日报告
- 指令: `#水王 今日报告` / `#水王日报`
- Demo: water-ranking.png
#### 说明
这是一个群管理可用的主动报告入口，主要用于日常查看和手动调试。

报告窗口固定为“今天 00:00 到当前时刻”的实时快照，和自动推送的昨日报告共用同一套报告骨架。

同一群共享 1 分钟冷却；任意管理触发后，60 秒内再次请求会直接返回剩余冷却时间。
#### 前置条件
需要在群聊中使用，并且触发者是当前群管理员、群主或超管。
#### 完整流程
```demo
USER: #水王 今日报告
BOT: 凛凛统计中，请稍后喔……
BOT: [发送今日群报告图片]
USER: #水王日报
BOT: 凛凛统计中，请稍后喔……
BOT: [发送今日群报告图片]
USER: #水王日报
BOT: 本群报告冷却中，请 58s 后再试 qwq
```
#### 失败情况
非群聊会直接拒绝；非群管理没有权限触发；当天还没有可用数据时会提示当前暂无可用报告。

### `achievement` 查看个人成就
- 摘要: 查询当前已解锁与下一步成就。
- 别名: 成就
- 指令: `#水王 成就`
- Demo: water-achievement.png
#### 说明
成就页面会汇总已解锁成就，并提示下一步最接近的目标。
#### 前置条件
需要在群聊中使用，并且用户至少有基础活跃记录。
#### 完整流程
发送成就子命令即可。
```demo
USER: #水王 成就
BOT: ===== 成就总览 =====
[成就进度文本或图片]
```
#### 失败情况
如果当前没有足够数据，可能会只返回基础提示，不会展示完整进度。

### `season-query` 查看赛季数据
- 摘要: 查询赛季概览、积分、排名与成就视图。
- 别名: 赛季
- 指令: `#水王 赛季` / `#水王 赛季 列表` / `#水王 赛季 当前列表` / `#水王 赛季 <season_id|名称> [个人|群聊|矩阵] [概览|积分|排名|成就]`
- Demo: water-season-query.png
#### 说明
赛季查询支持默认概览、当前赛季、赛季列表，以及指定 `season_id|名称` 后查询个人、群聊或矩阵视图。
#### 前置条件
需要当前系统已创建并发布至少一个赛季。
#### 完整流程
可先看列表，再查指定赛季。
```demo
USER: #水王 赛季 列表
BOT: [发送已发布赛季列表]
USER: #水王 赛季 spring2026 个人 积分
BOT: [发送赛季积分图]
```
#### 失败情况
如果赛季不存在、为空或命名歧义，会返回明确提示并建议先看赛季列表。

### `merge-confirm` 处理矩阵合并建议
- 摘要: 对智能建议发送 `#water.merge yes/no`。
- 别名: merge, 合并建议
- 指令: `#water.merge yes` / `#water.merge no`
- 权限: 群管理员
- Demo: water-merge-confirm.png
#### 说明
当系统判断某些群可能属于同一矩阵时，会提示管理员确认。管理员可通过 `yes` 或 `no` 完成一次性选择。
#### 前置条件
当前群存在待确认的合并建议，且执行者是群主、群管理员或超级管理员。
#### 完整流程
收到提示后执行一次选择即可。
```demo
BOT: 检测到矩阵合并建议...
USER: #water.merge yes
BOT: 已记录为“同意合并”啦
```
#### 失败情况
如果当前群没有待确认建议，或这个群已经做过选择，会返回锁定/无需操作提示。

### `admin-maintenance` 超管维护命令
- 摘要: 结算、回档、忽略、状态与赛季管理。
- 别名: water 管理, 超管命令
- 指令: `#water help` / `#water settle [YYYYMMDD] [-f|--force]` / `#water pardon <penalty_id>` / `#water ignore <group_id>` / `#water ignored` / `#water state` / `#water season create <season_id> <YYYYMMDD> <YYYYMMDD> <name>` / `#water season publish <season_id>` / `#water season archive <season_id>` / `#water season show <season_id>` / `#water season list [current|published|archived|draft]` / `#water season delete <season_id>`
- 权限: 超级管理员
- Demo: water-admin-maintenance.png
#### 说明
这组命令仅对超级管理员开放，覆盖 `help`、`settle`、`pardon`、`ignore`、`ignored`、`state`、`season create/publish/archive/show/list/delete`。
#### 前置条件
执行者必须是超级管理员。
#### 完整流程
先看帮助，再执行具体动作。
```demo
USER: #water help
BOT: ===== Water Admin =====
1. settle [YYYYMMDD] [-f|--force]
2. pardon <penalty_id>
USER: #water settle 20260608 -f
BOT: Water 结算任务执行中，请稍候...
```
#### 失败情况
参数错误、日期格式错误、事务已结算或对象不存在时，都会返回明确失败文案。
