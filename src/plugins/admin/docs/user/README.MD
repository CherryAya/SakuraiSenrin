# 用户管理模块

## 概览
用户管理模块采用 shell 风格参数解析，用于管理用户黑名单、解除黑名单以及查看当前状态。

## 权限与触发
- 触发方式: 指令触发
- 权限: 超级管理员

## 用法
- Help: `admin.user`

## 子功能目录
- `ban` 封禁用户: 把用户加入全局或群级黑名单。
- `unban` 解封用户: 从黑名单中移除用户。
- `status` 查询用户状态: 查看用户当前是否被封禁。

## 子功能详情
### `ban` 封禁用户
- 摘要: 把用户加入全局或群级黑名单。
- 别名: 拉黑
- 指令: `#admin.user ban <uid...> [-g <group>] [-r <reason>] [-t <duration>]`
- Demo: admin-user-ban.webp
#### 说明
> [!TIP]
> `ban` 支持一次处理多个用户。
>
> 可以按需补 `-g` 指定群范围、`-r` 记录原因、`-t` 设置时长；不传 `-g` 时默认写入全局黑名单。
#### 前置条件
目标用户必须已经在数据库中存在，且不能是超级管理员。
#### 完整流程
先准备用户 ID，再按需补充范围和时长参数。
```demo
USER: #admin.user ban 12345 -r 恶意刷屏 -t 1d
BOT: [12345|测试用户] 已封禁 (时长: 1天 范围: GLOBAL_GROUP)
```
#### 失败情况
非法用户 ID、时间格式错误、目标用户未入库或目标群不存在时，都会返回明确错误。

### `unban` 解封用户
- 摘要: 从黑名单中移除用户。
- 别名: 加白
- 指令: `#admin.user unban <uid...> [-g <group>] [-r <reason>]`
- Demo: admin-user-unban.webp
#### 说明
> [!TIP]
> `unban` 会按你传入的范围解除黑名单记录。
>
> 如果之前是群级封禁，就需要带上对应群范围才能精确解封。
#### 前置条件
目标用户当前需要存在匹配范围内的黑名单记录。
#### 完整流程
传入用户 ID 和可选的群范围。
```demo
USER: #admin.user unban 12345
BOT: [12345|测试用户] 已解封
```
#### 失败情况
如果用户当前未被封禁，会提示“未封禁”。

### `status` 查询用户状态
- 摘要: 查看用户当前是否被封禁。
- 别名: 状态
- 指令: `#admin.user status <uid...>`
- Demo: admin-user-status.webp
#### 说明
> [!TIP]
> `status` 只负责查状态，不改数据。
>
> 适合在执行封禁或解封前先确认当前用户到底处于什么状态。
#### 前置条件
目标用户已在数据库中存在。
#### 完整流程
直接输入用户 ID。
```demo
USER: #admin.user status 12345
BOT: [12345|测试用户] 状态: 正常
```
#### 失败情况
如果用户未入库，会提示“这位用户还没有和凛凛聊过”。
