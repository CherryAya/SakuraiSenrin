# 语言管理模块

## 概览
语言管理模块用于控制全局默认语言和群级语言覆盖，支持查看当前生效语言、设置默认值、设置群覆盖、清除覆盖以及列出所有覆盖。

## 权限与触发
- 触发方式: 指令触发
- 权限: 超级管理员

## 用法
- Help: `admin.i18n`

## 子功能目录
- `show` 查看当前语言: 查看全局默认语言和目标群的生效语言。
- `default` 设置全局默认语言: 修改项目默认语言。
- `set` 设置群级覆盖: 为某个群单独指定语言。
- `clear` 清除群级覆盖: 移除指定群的语言覆盖。
- `list` 列出覆盖: 查看所有群级语言覆盖记录。

## 子功能详情
### `show` 查看当前语言
- 摘要: 查看全局默认语言和目标群的生效语言。
- 别名: 查看
- 指令: `#admin.i18n show [gid]`
- Demo: admin-i18n-show.webp
#### 说明
`show` 会展示全局默认语言、群级覆盖以及最终生效结果。
#### 前置条件
若不在群聊上下文，需要显式传入群号。
#### 完整流程
先查看当前状态，再决定是否修改。
```demo
USER: #admin.i18n show 114514
BOT: ===== i18n 状态 =====
全局默认: zh-CN
生效语言: lzh
```
#### 失败情况
不在群聊且没有提供群号时，会提示显式提供群号。

### `default` 设置全局默认语言
- 摘要: 修改项目默认语言。
- 别名: 默认语言
- 指令: `#admin.i18n default <locale>`
- Demo: admin-i18n-default.webp
#### 说明
该操作会更新全局默认语言，影响没有群级覆盖的场景。
#### 前置条件
传入的语言代码必须属于 `zh-CN`、`lzh`、`x-meme` 或其支持的别名。
#### 完整流程
指定一个合法语言代码即可。
```demo
USER: #admin.i18n default x-meme
BOT: 已更新全局默认语言: x-meme
```
#### 失败情况
不支持的语言代码会返回可用值列表。

### `set` 设置群级覆盖
- 摘要: 为某个群单独指定语言。
- 别名: 设定
- 指令: `#admin.i18n set <locale> [gid]`
- Demo: admin-i18n-set.webp
#### 说明
群级覆盖优先级高于全局默认语言。
#### 前置条件
必须能确定目标群号；若不在群聊上下文，需要手动传入。
#### 完整流程
指定语言后再指定群号，或在群里直接执行。
```demo
USER: #admin.i18n set lzh 114514
BOT: 已更新群 114514 的语言覆盖: lzh
```
#### 失败情况
非法群号或非法语言代码都会直接报错。

### `clear` 清除群级覆盖
- 摘要: 移除指定群的语言覆盖。
- 别名: 清除
- 指令: `#admin.i18n clear [gid]`
- Demo: admin-i18n-clear.webp
#### 说明
清除后该群会重新继承全局默认语言。
#### 前置条件
需要能确定目标群号。
#### 完整流程
在群内可不传群号，私聊里建议显式传入。
```demo
USER: #admin.i18n clear 114514
BOT: 已清除群 114514 的语言覆盖。
```
#### 失败情况
若该群本来就没有覆盖，会提示“当前没有语言覆盖”。

### `list` 列出覆盖
- 摘要: 查看所有群级语言覆盖记录。
- 别名: 列表
- 指令: `#admin.i18n list`
- Demo: admin-i18n-list.webp
#### 说明
用于全局排查目前有哪些群配置了特殊语言。
#### 前置条件
无。
#### 完整流程
直接执行即可。
```demo
USER: #admin.i18n list
BOT: ===== 群级语言覆盖 =====
- 114514: lzh
```
#### 失败情况
如果没有任何群级覆盖，会提示当前为空。
