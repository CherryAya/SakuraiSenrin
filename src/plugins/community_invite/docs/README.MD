# 邀请凛凛入群须知

## 概览
如果您也想领养一只凛凛的话，还请阅读下面说明哦！

## 权限与触发
- 触发方式: 命令触发
- 权限: 普通用户

## 用法
- Help: `invite`
- 指令: `#invite`

## 说明
> [!TIP]
> 发送 `#invite` 后，凛凛会先把入群前的约定和注意事项一次讲清楚。
>
> 这不是审批指令，而是邀请前说明页。

## 完整流程
```demo
USER: #invite
BOT: 1.首先要取得管理层的同意，告知各个管理以及群主，因为经常会出现拉群之后就被群里不知道的管理者当成bot、或者嫌太吵直接踢出群聊，大家都没意见的话再看下文。
2.请不要禁言凛凛，禁言凛凛的话凛凛会自己退群，谨记这点，另外全体禁言则无妨。
3.不许滥用以及恶意添加词条，词条准则详情见#help wordbank
4.讨厌凛凛或者觉得太吵闹的话，可以自己屏蔽凛凛，或者联系管理员拉黑，从而不触发您的词条。
5.如果需要凛凛退群的话，还请在群聊中直接输入#remove，根据引导进行退群，当然您也可以直接将凛凛踢出群聊，这样做的话我们会将您与您的群拉黑，永远。当然您都这样子做了，想必也不是很在乎惩罚。
6.若以上都有好好阅读完觉得并没有什么问题的话，就加入下图的反馈群联系管理层以邀请凛凛加入群聊，有什么问题、建议以及bug可以在反馈群中及时反馈，我们会好好阅读每一条留言。
祝旅途愉快，每一种境遇都是命运的付赠品，还请好好珍惜，也希望能和凛凛相处的开心。
```
