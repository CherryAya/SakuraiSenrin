# 邀请凛凛入群须知

## 概览
这是一个虚拟社区说明节点，用于告诉群友在邀请凛凛入群前需要先了解哪些事项。

## 权限与触发
- 触发方式: 命令触发
- 权限: 普通用户

## 用法
- Help: `invite`
- 指令: `#invite`

## 说明
用户发送 `#invite` 后，凛凛会展示邀请她加入新群前的注意事项与基本流程说明。

当前插件仅作为社区文档节点存在，用于在帮助系统中说明该功能入口。

## 前置条件
无。

## 完整流程
```demo
USER: #invite
BOT: 请先查看邀请凛凛入群的须知，并按说明完成后续操作。
```

## 失败情况
当前为纯说明节点，没有额外失败分支；若帮助系统不可用，则不会返回该说明。
